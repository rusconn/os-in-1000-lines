# os-in-1000-lines

[1000行でOSを作ってみよう](https://operating-system-in-1000-lines.vercel.app/ja/)をやる。

## 環境

- macOS
- Homebrew(必要ツールのインストール)
- mise(LLVMユーティリティへのパス設定)
- Lazyvim+lang.clangd

## ツールのインストール

```sh
brew install llvm lld qemu
```
